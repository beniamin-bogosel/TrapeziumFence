# Documentation

This folder contains the LaTeX documentation for the `TrapeziumFence` verifier.

Build with:

```sh
make
```

The repository Makefile defaults to `OMP=auto`; use `make OMP=0` for a
deterministic serial build or `make OMP=1` to require OpenMP.

The main source is `main.tex`.  The PNG figures used by the experiment section
are generated by `make_survivor_rectangles.py` and stored in `figures/`.
The three-panel horizontal variant is
`figures/survivor_rectangles_three_panel.png`.

The documented pair-equality exclusion is conditional on Proposition 17 (and
the paper's analytic reduction to cases with both opposite-pair fences active).
Current files call these leaves `pair_incompatible`; the verifier also accepts
the legacy JSON status `nonoptimal`.

When regenerating the figures, the script uses the exact survivor endpoints,
including the common vertical interval
`[2835/4096, 2957/4096] = [0.692138671875, 0.721923828125]`.  Do not shorten
rectangle endpoints by inward rounding.
